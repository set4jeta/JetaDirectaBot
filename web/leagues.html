Frequently asked questions

How many leagues can you follow at once?

A server can follow up to 4 leagues at the same time. It is not a commercial decision: it is the ceiling set by Riot's API request quota so that one detection pass fits inside its interval. The free plan follows one.

Why does the LPL not have live alerts?

Because Chinese players play on servers that Riot's API does not expose. For the LPL you can see ranks and standings, but the game in progress cannot be detected, so it is not promised.

Where do these player counts come from?

From measuring each league's leaderboard: 919 distinct players across the 20, measured on 2026-09-03. It is the same measurement that set the league limit per server.

What is the difference between a league with ranks and one with accounts?

The ranks come from the league leaderboard: name, team, role, rank, wins and KDA for 919 players. Accounts have to be indexed player by player and add each player's Riot ID and their champion history with games and damage per minute. That second part is done for the LEC and gets done for a league when a server follows it.
