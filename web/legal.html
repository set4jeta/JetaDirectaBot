Terms and Privacy

Last updated: 2026-09-29

This document covers LoLProTrackr (the “bot”), a Discord bot that posts alerts when professional League of Legends players queue up for solo queue, and this website.

Terms of Service · Privacy Policy

Terms of Service

1. Acceptance

By adding LoLProTrackr to a Discord server or using its commands you accept these terms. If you do not agree, kick the bot from the server: there is nothing else to do to stop using it.

2. What is offered and at what price

The main feature —the game alert and the information it carries— is free and always will be. Paid plans only raise the limits (simultaneous leagues, alert channels and history size). No plan grants an in-game advantage or information that is not already public.

Payments, when they exist, will be made by subscription or donation. There is no gambling, no loot boxes and no currency that can be exchanged back into real money. The prices shown on this site are indicative and do not constitute an offer until an active payment method exists.

3. Acceptable use

You may not use the bot to harass players, automate large volumes of requests, resell access or get around the service limits. Access can be withdrawn from a server that does any of those things, without prior notice if the abuse affects everyone else.

4. No warranties

LoLProTrackr is provided “as is”. Data comes from the Riot Games API and from public esports sources; it can arrive late, incomplete or not at all. No guarantee is given that an alert will be posted, that a piece of data is accurate, or that a player identified as a professional still is one. No liability is accepted for decisions made on the basis of this information.

5. Interruptions and changes

The service depends on the Riot Games API and on Discord, and can be interrupted when either of them fails, when the request quota runs out, or during maintenance. Features and limits may change; if a change reduces what a paying server already had, notice will be given in the support server before it is applied.

6. Refunds

As long as there is no automatic payment, there is nothing to refund. When the charge is made through Discord, Discord's refund policy applies; when it is made by donation, the amount contributed in the current month will be returned to anyone who asks for it in the support server listed on this site.

7. Contact and cancellation

For anything related to these terms, write in the support server listed on this site. To stop using the service, kicking the bot is enough; you can also stop only the alerts with /mute.

Privacy Policy

1. Who is responsible

The data controller is whoever operates LoLProTrackr, reachable in the support server listed on this site. There is no company behind it: this is a personal project.

2. Discord messages

The bot does not store messages. It holds the message content permission because prefix commands (!live) still work and Discord requires it in order to read them; messages are processed in memory to check whether they are a command and then discarded. They are not archived, analysed or sent to anyone. Using the / commands is recommended, since they require reading nothing.

3. What is stored

DataWhat forHow long
Server and channel ID To know where to post alerts and in which language. Until /mute runs or the bot is kicked.
Server language, leagues and plan To keep the configuration across restarts. Same as above.
IDs of games already announced To avoid sending the same alert twice to the same channel. 2 hours.
Public League of Legends player data Riot ID, PUUID, rank and current game of the professional players being followed, obtained from the Riot Games API. This is not data about the people using the bot. Refreshed continuously; the match history is trimmed.

No email address, password, IP address or payment method is asked for or stored. The bot has no user account: the unit of configuration is the Discord server, not the person.

4. Professional player data

The summoner names, PUUIDs, ranks and games the bot shows are public data obtained from the Riot Games API and from public esports sources, about the accounts of professional players. No data is collected from the League of Legends accounts of the people using the bot.

5. Who it is shared with

With nobody for commercial purposes. Data is sent only to the services the bot needs in order to work: Discord (to post the messages) and the Riot Games API (to look up games and ranks). It is not sold or transferred to third parties.

6. Your rights

You can delete all configuration for a server by kicking the bot or running /mute. To access, rectify or delete any other data, or to object to the processing, write in the support server listed on this site: you will get a reply within 30 days at the most.

7. Cookies

This site is static and uses no cookies of its own or from third parties. There is no analytics, no advertising and no cross-site tracking. If that changes, this section is updated before the change goes live.

8. Minors

The bot is intended for people who meet Discord's minimum age in their country (13, or higher where the law requires it). Data is not knowingly collected from anyone below that age; if it happens, it is deleted as soon as it is detected or reported.

9. Changes

If this policy changes, the date in the header changes and the change is announced in the support server listed on this site. The version in force is always the one on this page.
